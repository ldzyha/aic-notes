# AIC Notes

[English](README.md) · [Українська](README.uk.md)

AIC Notes — Markdown-редактор для VS Code desktop та Web. Він відкриває
кожний `*.md` у preview-first редакторі AIC і тримає одну нотатку на проєкт,
`<папка>/<назва папки>.note.md`, сторінку якої для активного файла показує Secondary Side Bar. Розширення не додає входу в Standard Notes,
запитів облікового запису чи синхронізації нотаток. Файлові операції виконує
обраний у VS Code провайдер. За потреби переносьте блоки вручну через Copy/Paste.

Те саме розширення працює у VS Code for the Web (`vscode.dev` і `github.dev`).
Відкрийте папку або репозиторій, потім Markdown-файл через **AIC Markdown**.
Редактор і пов’язані нотатки використовують файлову систему
відкритого середовища та Save/Undo VS Code. Репозиторії лише для читання можна
переглядати; запис нотаток та налаштування інструкцій агента потребують підтримки
запису. AIC не синхронізує файли: запис у репозиторій або хмару визначає провайдер,
який ви обрали у VS Code.

AIC працює зі звичайним Markdown без пароля застосунку чи зашифрованих просторів.
Розширення не відкриває й не конвертує `.aicnotes`; наявні файли залишаються без
змін. Секретні поля й далі маскуються в інтерфейсі, але зберігаються у Markdown
відкритим текстом. За потреби шифрування використовуйте засоби диска чи пристрою.

Підготовлений випуск **61.6.5** використовує спільне ядро **8.0.0** разом зі
Standard Notes AIC **52.7.6** та експериментальним браузерним пакетом **0.12.0**.
Рядок `---` після порожнього рядка ділить нотатку на картки сторінок, а
`--- <шлях>` прив’язує сторінку до файла. Linked Note показує сторінку нотатки
проєкту, прив’язану до активного файла, і утримує редагування та Undo в ній.
Sidecar-нотатки, закріплення, Trash і вкладки Current, Shared та Global вилучено;
наявні sidecar-файли `*.note.md` лишаються звичайним Markdown. Шаблони `/` відповідають
DDK, а `/aic` вставляє блок AIC. Доступність у магазинах перевіряється окремо.

PWA відкриває Markdown-файли й папки та редагує оригінали безпосередньо на диску.
У VS Code основний редактор показує відкритий документ, а Linked Note — нотатку
активного файла; мобільна навігація залишає більше місця редактору.
Необов’язковий ШІ на пристрої та спільна інструкція на основі DDK допомагають
редагувати документи. Імпорт папок рахує лише Markdown-файли, показує прогрес
і підтримує скасування. VS Code не зберігає відкритий документ після видалення
його файла. Синхронізацією керує користувач.

Порожні редаговані секретні частини (`*|`) показують **Generate password** на
будь-якій ширині панелі незалежно від назви. Параметри переносяться на вузьких
екранах. Генерація працює локально, не перезаписує заповнені значення й недоступна
в режимі читання.

Кнопка копіювання ненадовго показує галочку після успіху або хрестик після
помилки, зберігає доступну назву дії та повідомляє стан для читача екрана.
Більші заголовки секцій, окремий нейтральний фон груп і
легке чергування сірих рядків допомагають швидше знаходити записи.

Назви, email та логіни займають природну ширину. Спочатку ціле значення
переходить на наступний рядок; текст переноситься всередині лише тоді, коли
не вміщується на повній доступній ширині. Пароль має компактну кнопку копіювання
із замком, а короткі дані картки й TOTP-коди залишаються читабельними. Меню `+`
йде після останнього значення, записи розділяють легкі лінії. Сенсорні кнопки
зберігають область натискання 44 px.

Після виходу з редагування джерела AIC-блоку або перемикання всієї нотатки з
джерела у прев’ю рядки кожної секції сортуються за назвою: без урахування регістру
та з природним порядком чисел. Рядки без назви зберігають свій порядок наприкінці.
Порядок секцій, порядок значень і точний текст значень не змінюються. Відкриття
прев’ю, копіювання й ручне переставлення не запускають сортування.

Єдина двомовна інструкція встановлення: [`RELEASE_INSTALL.md`](RELEASE_INSTALL.md).

## AIC-поля і режим джерела

Головний редактор і Linked Note використовують той самий обмежений `aic` parser,
що й Standard Notes. Кожний розділювач задає тип наступного значення:

- `|` — текст;
- `*|` — секрет;
- `#|` — authenticator seed;
- `_|` — картка;
- `1|` — невикористане одноразове значення;
- `0|` — використане одноразове значення.

Назва перед першим розділювачем необов’язкова, а один рядок може поєднувати
кілька типів:

```aic
# Обліковий запис
Login | person@example.test
Password *| synthetic-secret
Card _| 4111111111111111 | 12/30 *| 123
Recovery codes 1| code-one 0| already-used
```

Blank, Card і One-time codes — шаблони цих частин, а не окремі формати. Field
додає типізовану частину до поточного рядка, Row — рядок нижче, Section — секцію
після поточної. Копіювання `1|` переводить код у `0|`; натискання використаного
значення повертає `1|` без копіювання.

Одна іконка **Show Markdown source / Show preview** перемикає прев’ю на місці,
не скидаючи Undo. Повернення у прев’ю застосовує описане вище сортування AIC-рядків
через звичайний цикл зміни документа. Сирий Markdown
може відкрити візуально масковані значення. Локальна довідка **?** працює без
мережі, нотатки та сховища.

Застарілі YAML Properties, colon fields і попередні Security formats лишаються
точним Markdown для ручного виправлення. Вони не мігрують автоматично й не
отримують часові мітки.

## Дії з полями безпеки

### Authenticator JSON

Відкрийте початковий JSON-масив або виділіть його повністю. Для валідних записів
із `service`, `account`, `secret` з’явиться **Convert and save security blocks**.
Перетворення створює один або кілька блоків `aic` із незалежними секціями:
Service/Account/Notes видимі, TOTP/Password та додаткові рядкові поля приховані.
Безпечна адреса сервісу отримує окреме URL-поле. Переповнення переходить у новий
блок без втрати даних.

Операція є однією undoable зміною і зберігається через того самого VS Code
менеджера. Вона не сканує обліковий запис, не читає буфер, не змінює типи нотаток
і не синхронізує дані. Некоректний запис, дублікат ключа чи непідтримуване
значення відхиляє весь масив. Межі: 256 записів і 1 МіБ UTF-8.

### Copy, Paste і password generation

Натисніть label, щоб скопіювати його, або value, щоб скопіювати значення.
Порожнє поле має Paste і Delete; заповнене — ні. Replace відсутній. Значення
редагується через Edit у Markdown source. Whole-block Copy лишається в заголовку.

Paste читає останній текст через нативний VS Code Clipboard API лише після
натискання. Історії, моніторингу й проміжного діалогу немає. Відмова або timeout
показує масковане поле лише для вставлення. Порожній буфер нічого не змінює.

Порожня редагована частина `*|` показує **Generate password** незалежно від назви
та ширини панелі.
Параметри переносяться на вузьких екранах; режим читання не дає генерації.
Типово: 24 символи; діапазон 8–128, великі/малі літери, цифри й символи.
Web Crypto працює локально, не перезаписує, не показує і не копіює значення
автоматично. TOTP та інші типи частин, окрім `*|`, не пропонують генерацію.

## Mermaid і Markdown

Mermaid редагується як Markdown-код із живим прев’ю. У прев’ю є Copy, одна
іконка Edit. Діаграма центрована, зменшується до доступної ширини та займає
власну висоту без внутрішніх скролів і кнопок масштабу.

`>` — інформаційна цитата, `!>` — warning, `!>>` — error, а `>>> … <<<` —
details/accordion. Цитати мають легкий фон і боковий акцент; цитований та italic
текст менші. Горизонтальна лінія центрована, має ширину 50–100 px і вертикальні
відступи. Незавершений три-backtick fence лишається редагованим, а готовий блок
показує прев’ю після виходу курсора.

## Модель пов’язаних нотаток

- Кожний проєкт (робоча папка) має одну нотатку в корені, названу за папкою:
  `<папка>/<назва папки>.note.md`, наприклад `my app/my app.note.md`. Коли
  робочих папок кілька, нотатку обирає папка активного файла.
- Linked Note показує лише сторінку нотатки проєкту, прив’язану до активного
  файла. Файл без сторінки показує порожню картку.
- Перегляд файла ніколи не створює й не змінює нотатку проєкту. Перший введений
  текст додає сторінку, а перше збереження створює відсутню нотатку.
- Коли активна сама нотатка проєкту, не файлова вкладка або файл поза робочою папкою,
  Linked Note показує всю нотатку картками.
- Зміна активного файла лише переносить фокус сторінки; незбережена чернетка
  лишається.
- Коли нотатка проєкту змінюється, поки Linked Note має незбережений текст, чернетка не
  замінюється. Збереження записує сторінки чернетки у змінену нотатку, якщо ці
  сторінки там не змінилися; інакше нічого не записується, чернетка лишається,
  а нижня панель пропонує «Discard my changes and reload» із підтвердженням.
- Нотатка проєкту з такою назвою з версій до 60.x використовується як є: її текст
  лишається першою сторінкою, і нічого в ній не переписується, доки ви не
  редагуєте. Інші файли `*.note.md` лишаються звичайними Markdown-файлами, і
  панель за ними не слідує.
- Версія 61.6.5 тримала нотатку в `<папка>/aic.md`. Панель за цим файлом більше
  не слідує й ніколи його не змінює та не видаляє; якщо ви ним користувалися,
  скопіюйте його сторінки в нотатку проєкту.

### Сторінки нотатки

Нотатка — це блокнот. Рядок, що складається лише з `---`, перший у тілі або
після порожнього рядка, поза блоком коду та початковим frontmatter, починає нову
сторінку; `--- src/app/editor.ts` прив’язує цю сторінку саме до цього файла
відносно проєкту (через `/`, без початкових `./` чи `/`). Нотатка лишається одним файлом. Кожна сторінка — картка,
заголовок якої називає ціль; **Open target** відкриває цей файл в основному
редакторі або http(s)-ціль у браузері й є єдиною дією картки. Папки та шляхи
поза проєктом відхиляються.
Прив’язаний рядок починає свою сторінку навіть усередині незакритого блоку
коду, тож блок коду ніколи не виходить за межі своєї сторінки.
Undo лишається в межах сфокусованої сторінки.

## Збереження й видалення

Save, Ctrl/Cmd+S і вихід із поверхні використовують один менеджер persistence.
Security preview actions запитують негайне збереження. Лише підтверджений запис
прибирає dirty state. Помилка лишає чернетку для retry.

Розширення не має дії видалення: воно ніколи не видаляє, не переміщує й не
перейменовує файл нотаток.

## Команди

- **Open Note Page for Current File** (`Ctrl/Cmd+Alt+N`) — показати в Linked
  Note сторінку активного файла з нотатки проєкту.
- **Use Native Editor for Plain Markdown** — повернути нативний VS Code editor.
- **Enable/Sync AIC Agent Workflow** — необов’язкові локальні інструкції для
  agent workflow.

## Вбудовані інструкції для агентів

AIC Notes містить інструкції для будь-якого агента, який може читати Markdown.
Окремий виконуваний файл AIC, сервер або каталог конфігурації не потрібні.
**Copy Agent Instructions** копіює текст; той самий текст доступний у довідці **?**.

Інструкція (версія 4) вказує агентам на нотатку проєкту
`<назва папки>.note.md` як на контекст власника лише для читання: її початковий
текст і сторінку, прив’язану до файла, який змінюють. `aic context resolve --path
<file>` повертає той самий контекст користувачам `aic`; інші агенти читають
нотатку безпосередньо. Агенти не створюють нотатку й не додають сторінок. Старіші
файли `*.note.md` для окремих файлів і папок читаються, якщо є, але не
створюються. Вміст нотатки є свідченням у межах чинних інструкцій проєкту, а не
дозволом виконувати команди.

У довіреному робочому просторі **Enable AIC Agent Workflow** створює незмінну
копію `.vscode/aic-agent-<content-hash>.md` та маркер `.vscode/aic-agent.json`.
**Copy handoff** копіює шлях для передачі агенту. **Sync Agent Instructions**
оновлює лише цю локальну передачу; глобальна синхронізація AIC більше не запускається.
Назва файла походить від хеша інструкції, тож коли оновлення змінює її, наступні
**Enable** або **Sync** записують новий файл і спрямовують на нього маркер;
попередній файл лишається на місці.
Старі маркери мігрують лише за явною командою. Змінені користувачем інструкції,
`AGENTS.md` та налаштування провайдерів зберігаються. Встановлення або оновлення
розширення не запускає CLI й не змінює глобальні інструкції.
